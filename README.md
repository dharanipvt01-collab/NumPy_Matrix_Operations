# NumPy Matrix Operations

## Project Overview
This project demonstrates basic matrix operations using Python and NumPy as part of the Veda Technology AI & ML internship, Day 14 task.

## Objective
To understand matrix addition, subtraction, multiplication, and transpose operations used in mathematics and machine learning.

## Technologies Used
- Python
- NumPy
- VS Code

## Operations Implemented
1. Matrix addition
2. Matrix subtraction
3. Matrix multiplication
4. Transpose of Matrix A
5. Transpose of Matrix B

## How to Run
1. Install Python.
2. Install NumPy using `python -m pip install numpy`.
3. Open the project folder in the terminal.
4. Run `python app.py`.

## Matrix Multiplication
Matrix multiplication multiplies each row of the first matrix by each column of the second matrix and sums the products. The number of columns in the first matrix must equal the number of rows in the second matrix.

## Expected Outcome
The program displays two matrices and the results of addition, subtraction, matrix multiplication, and transpose operations.

## Learning Outcome
This project improves understanding of NumPy arrays and basic mathematical operations commonly used in data analysis and machine learning.
